# Customer Churn Prediction using Artificial Neural Network (PyTorch)

## Overview
This project implements an Artificial Neural Network (ANN) using PyTorch to predict customer churn based on bank customer data. Customer churn prediction is a critical problem in industry, helping organizations identify customers who are likely to leave and enabling proactive retention strategies.

This project demonstrates the practical implementation of deep learning concepts including neural networks, forward propagation, backpropagation, and gradient descent.

---

## Objectives
- Build a deep learning model using PyTorch
- Apply ANN for binary classification
- Understand neural network training and optimization
- Gain hands-on experience with real-world structured data
- Learn model evaluation and performance improvement techniques

---

## Dataset
Dataset used: Credit Card Customer Churn Prediction Dataset

Features include:
- Credit Score
- Geography
- Gender
- Age
- Balance
- Estimated Salary
- Tenure
- Number of Products
- And other customer attributes

Target variable:
- Exited (0 = No Churn, 1 = Churn)

---

## Model Architecture
Artificial Neural Network with:

- Input Layer
- Hidden Layer 1 (ReLU activation)
- Hidden Layer 2 (ReLU activation)
- Output Layer (Sigmoid activation)

Loss Function:
- Binary Cross Entropy Loss

Optimizer:
- Adam Optimizer

---

## Training Process
The model learns using:

- Forward propagation
- Loss calculation
- Backpropagation
- Gradient descent optimization

The network adjusts weights iteratively to minimize prediction error.

---

## Results
Final Model Accuracy Achieved:

**86.05%**

This demonstrates effective learning and strong predictive capability.
